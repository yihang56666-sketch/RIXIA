# 平板播放器与学习工作台改造设计

## 目标

让 Android 平板和手机上的 BEID 在系统返回、视频播放控制、弹窗布局、时间点笔记和考研计划上达到可连续使用的状态，并为第三方网盘资源提供明确、可控的接入入口。

## 范围与边界

1. 返回行为统一由应用导航状态和 Android `Back` 事件驱动：全屏先退出全屏，弹窗先关闭，播放器先返回来源页，普通页面再返回上一级；没有历史时回到首页。
2. 播放器控制栏在原生 Media3 与浏览器 MSE 两条路径保持同一组能力：播放/暂停、进度、音量/静音、倍速、清晰度、分 P、字幕、弹幕、循环、定时关闭、全屏和画中画。控件在窄屏用可横向滚动的控制带和底部抽屉承载，不能被裁切。
3. 时间点笔记保存后立即显示成功状态、时间点和可撤销入口；失败显示可重试原因。
4. 考研计划重做为“目标概览、阶段计划、今日任务、复习记录”四块，数据继续使用本地 store，先保证离线可用。
5. 网盘资源先加入资源来源选择和外部打开/导入入口。夸克、百度网盘的登录、授权和受保护流媒体不绕过官方权限；需要扫码时停在授权页面等待用户。

## 数据流与错误处理

页面动作 -> 统一导航/播放器控制接口 -> 平台实现（Web 或 Android） -> 状态事件 -> 页面反馈。所有异步动作都必须有 loading、成功和失败状态；第三方资源只保存用户明确提供的链接、名称和来源，不保存账号密码。

## 验收标准

- Android 系统返回键在播放器、弹窗、全屏和普通页面均按上述优先级工作。
- 1840x2944 平板横竖屏及 390px 手机宽度下，播放器所有控制可见、可点击、可滚动；音量/倍速/清晰度实际作用于原生播放器。
- 保存笔记后 1 秒内出现明确成功反馈，刷新页面仍能看到笔记。
- 考研计划可创建目标、编辑阶段、勾选今日任务、记录复习，并显示进度。
- 网盘入口不会声称已支持受保护视频直播放；未授权时给出清晰下一步。
- 现有自动化测试和 Android 构建保持通过，实体平板回归无崩溃。
