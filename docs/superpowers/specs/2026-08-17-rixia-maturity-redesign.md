# RIXIA 成熟化改版与学习能力融合设计

日期：2026-08-17

## 1. 背景与目标

RIXIA 已有任务、习惯、笔记、倒计时、专注、考研计划、B 站视频收藏、PWA、Android 壳和八套配色主题。现状的主要问题不是功能不足，而是功能之间缺少主次关系：页面依赖同形态卡片逐层堆叠，桌面空间利用率低，移动端首屏被统计卡占满，底部导航会遮挡内容，主题只改变颜色而没有改变材质和氛围。FocuBili 的当前融合则是把 RIXIA 作为 Android WebView 页面嵌入另一个应用，Windows 端尚未加载工作台，两边数据也互不相通。

本次改版的目标是把 RIXIA 升级为统一的个人节奏与学习工作台：界面安静、克制、顺滑，信息更丰富但只在需要时展开；同一套产品语言覆盖 Windows、平板和手机；FocuBili 成为学习播放能力来源，而不是第二套产品外壳；主题从换色升级为完整的视觉皮肤。

## 2. 已选方向

采用“统一 RIXIA + 可替换学习引擎”方案。

- RIXIA 负责品牌、导航、首页、计划、专注、资料库、主题和跨端布局。
- 学习区通过 `LearningProvider` 接口访问搜索、课程详情、播放、进度和时间点笔记能力。
- Web/PWA 使用官方 B 站嵌入播放器和外部打开作为安全降级。
- Android 和 Windows 合体版通过原生宿主桥接 FocuBili 的搜索、播放、进度和笔记服务。
- 不继续维护“RIXIA 与 FocuBili 各有一套顶级导航”的产品形态。

这一方向保留现有 React 功能和 PWA 跨端能力，同时允许逐步复用 FocuBili 已验证的原生播放能力。它比全面迁移 Flutter 风险更低，也比纯 Web 重写更符合直接融合开源代码的诉求。

## 4. 产品信息架构

顶级导航减少为五个稳定目的地：

1. **今天**：下一步行动、今日进展、继续学习和近期节奏。
2. **计划**：任务、考研科目、习惯和倒计时的统一规划入口。
3. **专注**：计时器、环境音、专注目标和历史趋势。
4. **资料库**：课程、视频、笔记和稍后处理内容。
5. **设置**：外观、模块、数据、隐私、许可证和设备能力。

“收集箱”不再占用永久导航位，而是成为全局快速捕获入口；桌面使用侧栏底部的捕获按钮和 `Ctrl/Cmd + K`，移动端使用导航上方的浮动捕获按钮。低频管理动作进入对应页面的工具栏或上下文菜单。

## 5. 首页设计

首页不再是卡片墙，而是三层内容：

### 5.1 主行动区

首屏只突出一个“下一步”：继续最近课程、开始当前任务的专注回合，或整理收集箱。它包含日期、简短状态、主按钮和当日总进度，不使用独立营销式大卡。

“下一步”按固定优先级选择：恢复正在进行的专注回合；处理已逾期或今天到期的首个未完成任务；继续最近 7 天看过但未完成的课程；处理收集箱；最后回退为创建今日任务。用户可以手动切换候选项，应用不会用随机推荐改变顺序。

### 5.2 紧凑状态带

任务完成数、习惯打卡、专注分钟、收集箱和最近倒计时使用一条可横向滚动的状态带呈现。每项是紧凑指标，不是独立阴影卡；点击进入详情。移动端首屏最多显示三项，其余横向滚动。

### 5.3 情境内容区

- 今日安排：按时间和优先级组织的任务与考研单元，可直接完成。
- 继续学习：最近观看课程、播放进度、关联专注目标和最新时间点笔记。
- 节奏回顾：默认只显示一句趋势摘要，展开后显示 7 天图表。
- 今日习惯：默认显示未完成项，已完成项折叠为一行摘要。

桌面和平板使用双栏，移动端按主行动、状态带、今日安排、继续学习的顺序单列排列。

## 6. 视觉系统

### 6.1 层级

页面只使用三种空间层级：应用背景、导航材质、内容表面。模糊仅用于导航、底部栏、弹层和确有背景穿透意义的浮动控件；普通内容区使用实色或轻透明表面，避免每个模块都像塑料玻璃卡。

- 重复项目可以使用轻边界容器。
- 页面分区不包成悬浮卡。
- 阴影只用于浮层、选中态和真正离开页面平面的控件。
- 圆角按 6/8/12/16 四档使用，普通卡片不超过 8px；大圆角只用于底部栏和模态表单。

### 6.2 字体与密度

使用系统字体栈，Windows 优先 Segoe UI Variable，Apple 平台优先 SF Pro 系统字体。字号不随视口缩放。标题、数字、正文和辅助信息使用固定层级与正常字距；指标数字使用等宽数字特性。默认密度适合触控，桌面可选择“舒展/标准/紧凑”三档。

### 6.3 动效

- 导航切换使用 220–320ms 的淡入、轻位移和共享选择背景。
- 列表新增、完成与折叠使用局部布局动画，不让整页重复入场。
- 按钮按下使用 0.98 缩放与亮度反馈；悬停只在有鼠标的平台启用。
- 所有动效尊重 `prefers-reduced-motion`。
- 计时器和进度更新保持布局尺寸固定，避免跳动。

### 6.4 皮肤

皮肤不再只是主题色，至少包含背景、表面材质、强调色、成功/警告色、阴影、模糊、插图或纹理策略和深浅模式。首批提供：

- Porcelain：清透中性白，彩色强调，默认高级浅色。
- Graphite：近黑中性表面，低反射，默认高级深色。
- Sage：灰绿与暖白，适合长时间学习。
- Aurora：冷白、青绿与珊瑚强调，避免单一蓝紫色调。
- Rosewood：柔和玫红与深灰，不使用大面积粉色。
- Mono：高对比黑白，最少装饰。
- Ocean：海水青、深靛与中性白，强调专注区。
- Ember：冷灰表面配琥珀强调，避免大面积橙棕背景。
- Lavender：中性灰表面配少量薰衣草强调，不使用紫色渐变。
- Ink：墨黑、纸白与朱红点缀，适合高对比阅读。
- System：跟随系统深浅模式和强调色。

首批共十套独立皮肤加一套 System 自动模式，比现有八套增加三种选择。现有主题键通过迁移映射到最接近的新皮肤，保留用户选择。

## 7. 学习能力融合

定义稳定接口：

```ts
interface LearningProvider {
  capabilities(): Promise<LearningCapabilities>;
  search(query: string, filters?: LearningFilters): Promise<CourseResult[]>;
  resolve(input: string): Promise<CourseResource>;
  openPlayer(resourceId: string, episodeId?: string): Promise<PlayerSession>;
  getProgress(resourceId: string): Promise<LearningProgress | null>;
  saveTimestampNote(note: TimestampNoteInput): Promise<TimestampNote>;
}
```

Web provider 负责 BV 号解析、官方嵌入播放、外部打开、RIXIA 本地进度与笔记。Native provider 通过宿主桥复用 FocuBili 服务。UI 只依赖接口，不直接判断 Flutter、Capacitor 或浏览器。

课程资料模型补充：课程/视频、分集、观看进度、最近播放时间、关联任务、关联专注回合和时间点笔记。资料库支持“继续学习”“稍后学习”“已完成”三个状态，不提供无限推荐流。

## 8. 数据与迁移

Zustand 持久化版本升级到 v2，并增加显式迁移：

- 现有 `videos` 转为 `CourseResource`。
- 现有主题键映射到新皮肤键。
- 现有任务、习惯、专注和考研数据保持原 ID。
- 导入时进行结构校验，失败不覆盖当前数据。
- 原生桥不可用时继续使用 Web provider，不丢失本地数据。

长期数据边界保持本地优先。跨设备同步不进入本轮范围，但备份格式保留版本号，为后续同步预留迁移能力。

## 9. 响应式策略

- **手机 `< 768px`**：底部固定显示“今天、计划、专注、资料库、设置”五个标签；单列；安全区内边距；主操作固定可达；任何固定栏不得覆盖正文。
- **平板 `768–1199px`**：窄侧栏或导航轨道；首页和资料库双栏；横屏利用 60/40 主次布局。
- **桌面 `>= 1200px`**：240–272px 侧栏；12 栅格内容区；最大内容宽度约 1440px；列表和详情可并排。
- 触控目标最小 44px；键鼠平台保留快捷键、悬停提示和右键/更多菜单。

## 10. 错误与降级

- 离线时课程搜索和在线播放显示明确离线状态，已有本地数据仍可浏览。
- B 站接口或嵌入失败时提供重试、外部打开和复制链接，不显示空白播放器。
- 原生桥版本不兼容时记录能力缺失并切换 Web provider。
- 导入、图片背景和本地存储失败使用非阻塞提示；破坏性操作二次确认。
- 所有异步视图具备加载、空、错误和部分数据四种状态。

## 11. 测试与验收

### 自动化

- 单元测试覆盖主题迁移、数据迁移、首页摘要、课程状态、Provider 降级和导入校验。
- 组件测试覆盖导航、主题选择、首页展开/折叠、播放器错误状态和键盘操作。
- Playwright 覆盖桌面 1440×900、平板 1024×1366、手机 390×844 和窄屏 360×800。
- 每个目标视口检查无横向溢出、无导航遮挡、无文本重叠、关键按钮可达。
- 构建验证包含 Web/PWA、Capacitor Android，以及合体版 Android/Windows 能力探测。

### 体验验收

- 手机首屏无需滚动即可看到下一步、三项核心指标和首个今日事项。
- 桌面首屏至少同时展示主行动、今日安排和继续学习，不留下无意义大面积空白。
- 切换皮肤时颜色、表面、阴影和背景同时变化，正文对比度保持可读。
- 动画连续但不妨碍快速操作，减少动画偏好下无强制位移。
- 无 FocuBili 原生桥的设备仍可完成添加课程、播放、记录进度和时间点笔记的基本流程。

## 13. 非目标

- 不实现社交、排行榜、无限推荐流或账号写操作。
- 不在本轮引入云账号、云同步或自建服务端。
- 不照搬 macOS/iOS 视觉，不使用苹果商标或受保护资源。
- 不为增加功能数量而加入与“计划、专注、学习、回顾”无关的工具。
