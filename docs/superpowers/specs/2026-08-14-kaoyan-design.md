# 考研区设计

## 目标

为 RIXIA 增加一个固定的“考研”底部导航入口，用于管理考研复习的大类和小类，并通过每日勾选跟踪计划周期内的学习进度。

## 信息结构

- **大类（科目）**：例如高数、英语、政治、数电、模电。用户可新建、编辑、删除和拖动排序；每项含名称和柔和的强调色。
- **小类（学习单元）**：从属于一个大类。用户可新建、编辑、删除和拖动排序；每项含名称、开始日期、结束日期和已完成日期列表。

## 进度和日期规则

- 小类的计划天数为开始日到结束日（含首尾）的自然日数量。
- 每日打卡在小类详情时间线中完成，也可使用小类卡片上的“今日完成”快捷操作。
- 小类进度为当前计划周期内已勾选日期数除以计划天数。
- 编辑日期后，仍位于新周期内的勾选日期继续保留；新周期外的历史勾选数据保留在记录中但不参与当前进度。
- 大类进度为其所有小类的计划天数加权完成率；没有小类时显示 0%。

## 页面与交互

### 考研首页

- 显示所有大类的名称、总体进度、已完成小类数、最近结束日期和细进度条。
- 提供新增大类入口；每个大类提供编辑、删除和排序操作。
- 点击大类进入详情页。

### 大类详情

- 显示大类标题、整体进度和小类列表。
- 每个小类显示名称、日期范围、完成率、倒计时/已结束状态与今日打卡按钮。
- 提供新增、编辑、删除和拖动排序小类操作。
- 点击小类进入详情页。

### 小类详情

- 显示名称、进度、开始日、结束日和总计划天数。
- 以周分组的纵向时间线展示该周期的所有日期；当天和完成状态明确区分。
- 任意日期可补打或取消，今日勾选可在卡片与详情之间同步。

## 视觉和可用性

- 保持现有移动端全屏背景能力。
- 使用 iOS 风格的宽留白、低圆角、半透明磨砂面板、细分隔线、浅阴影和克制的强调色。
- 在自定义背景下，通过遮罩与前景色保障文本、进度和按钮的可读性。
- 考研页是底部导航的固定入口，不受工具开关影响。

## 数据与兼容性

- 新数据并入现有 Zustand 持久化 store（`rixia-v1`）。
- 不更改已有收集箱、任务、习惯、笔记、倒计时、专注和背景数据结构。
- 所有功能离线可用，不要求账号或网络。

## 验证

- 单元测试覆盖日期区间、完成率、加权大类进度与日期修改后的有效记录筛选。
- 验证每日勾选、编辑和排序的 store 行为。
- 构建检查：测试、TypeScript 类型检查、Vite 构建、Capacitor 同步、离线 Gradle debug 构建与 APK 签名校验。
